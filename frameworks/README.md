# Zap Framework Starter Templates

ဤ directory သည် Zap ecosystem ၏ domain framework starter structure များကို ပြသသော scaffolding ဖြစ်သည်။

```text
frameworks/
  web/       Web server/API starter
  mobile/    Android/iOS application starter
  ai/        AI assistant/model application starter
  iot/       Sensor/device starter
```

Framework တစ်ခုချင်းစီသည် `zap.toml` manifest၊ `main.zp` entry file နှင့် နောက်ပိုင်းတွင် runtime adapter/package dependency များ ပါဝင်မည်။
