**Baseline:** Zap v2.2.6 is the current release candidate following the verified published v2.2.4 release. The v2.2.0, v2.2.1, and v2.2.2 tags and assets remain immutable, while the remaining partial items below continue as post-v2.2.4 engineering work.

**Detailed execution plan:** [`NEXT_TODO_PLAN_EN.md`](NEXT_TODO_PLAN_EN.md) defines the milestone sequence, implementation tasks, acceptance evidence, and release gates for the remaining work.

## Release policy

Each execution step must pass formatting, strict Clippy in the pinned CI toolchain, the full native test suite, relevant conformance tests, bilingual documentation parity, and `git diff --check`. Post-release corrections are recorded separately from the immutable v2.2.0 and v2.2.1 releases. The v2.2.2 release added the runtime-safety and canonical-helper corrections after its acceptance criteria, provenance record, and CI gates passed. The v2.2.3 release adds the post-v2.2.2 runtime-reliability hardening after the same gates pass, and v2.2.4 records the subsequent active-baseline documentation synchronization. The v2.2.6 candidate records HTTP URL parser-result, scheme, and host invariant errors without parser/runtime syntax or framework work. Future release tags require the same evidence.
