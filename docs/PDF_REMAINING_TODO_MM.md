## Release policy

အဆင့်တိုင်းတွင် pinned CI toolchain ဖြင့် strict Clippy၊ formatter၊ full native test suite၊ သက်ဆိုင်ရာ conformance tests၊ English/Burmese documentation parity နှင့် `git diff --check` အားလုံး အောင်မြင်ရမည်။ Post-release correction များကို immutable v2.2.0 နှင့် v2.2.1 release များမှ သီးခြားမှတ်တမ်းတင်ထားသည်။ v2.2.2 release တွင် နောက်ဆက်တွဲ runtime-safety နှင့် canonical-helper correction များကို acceptance criteria၊ provenance record နှင့် CI gate များ အောင်မြင်ပြီးမှသာ ထည့်သွင်းထုတ်ဝေထားသည်။ v2.2.3 release တွင် post-v2.2.2 runtime-reliability hardening များကို အလားတူ gate များ အောင်မြင်ပြီးမှသာ ထည့်သွင်းထုတ်ဝေထားသည်။ v2.2.4 release တွင် active-baseline documentation synchronization ကို မှတ်တမ်းတင်ထားသည်။ v2.2.6 candidate တွင် HTTP URL parser-result၊ scheme နှင့် host invariant error hardening ကို parser/runtime syntax သို့မဟုတ် framework work မပါဘဲ ထည့်သွင်းထားသည်။ နောက်ထပ် release tag များအတွက်လည်း အလားတူ evidence လိုအပ်မည်။
