## Current verification baseline

The native Rust suite currently passes its full unit and integration test baseline. The P1-05 deterministic and replayable layer runner passes its parser/lexer/JSON/lockfile/security corpus, six-category fixed-seed replay, durable fixture evidence, collection regression, and async cancellation/scheduler cases. The M2-VERIFY-01 bounded replay job repeats the six-category semantic replay for the configured rounds and confirms identical outcome digests under fail-closed corpus-size limits. The M2-VERIFY-02 matrix runs every listed target-native regression rather than accepting zero-test filter matches and records the platform archive result in the target log. The M2-REG-01 transport corpus runs chunked, truncated, delayed, and oversized response fixtures through the same client reader used by registry index and artifact fetches. The release preflight now runs ownership, native/legacy parity, fixed-seed replay, bounded replay, and focused async contract gates before deployment validation. The repository includes the runnable example [`examples/default_parameters.zp`](../examples/default_parameters.zp), synchronized English/Burmese type-narrowing, package, standard-library, benchmark, and release guides, and README links for the current learning materials. The native CLI version output matches the `v1.0.0` release line. `cargo fmt --check` and `git diff --check` pass. Stable Rust Clippy remains enforced by the GitHub Actions release workflow; it is not claimed as locally verified when the local sandbox lacks the Clippy component.

The gradual-typing baseline is complete at the supported syntax boundary: primitive and bounded generic annotations, function arguments and returns, option/result payloads, control-flow narrowing, structured diagnostics, and TC-001–TC-012 conformance evidence are documented in English and Burmese; advanced user-defined generic declarations and inference remain explicitly deferred. Clean-machine locked verification now proves that a copied project can run `zap install --locked` and `zap build --locked` without registry access and rejects a tampered lockfile. The direct-AST migration is complete for the current runtime call set, with nested-call audit coverage, native object construction, AST-evaluated defaults, and explicit unsupported-call diagnostics; parser-owned execution no longer hides a legacy expression reparse. The standard-library public surface has deterministic domain metadata and bilingual indexes. CI includes platform-specific CLI smoke checks. Package tooling supports deterministic local dependency declarations and canonical lockfile validation; remote registry resolution and publishing remain later ecosystem work. Named arguments are available for user-defined functions, methods, and closures. OOP covers method and field modifiers, protected inheritance access, field default initialization, field assignment checks, module-aware visibility, and constructor delegation rules. Control-flow narrowing handles single guards, `and`/`or` guard combinations, aliases, and restoration of the original option/result type after an `else` branch. P1 release documentation is synchronized in English and Burmese. Executor-backed async scheduling and cooperative task controls are now implemented. M2-VERIFY-02 platform-native hardening is complete, while benchmark provenance and registry transport edge cases remain before the M3 tooling/documentation milestones.
