# Zap P1 Language Core တိုးတက်မှု

## လက်ရှိအခြေအနေ

Zap P1 Language Core သည် `v1.0.0` release အတွက် ပြီးစီးပါပြီ။ Source၊ local verification နှင့် GitHub Actions release gate များကို စစ်ဆေးပြီးနောက် release tag ကို တင်ထားပါသည်။

## လက်ရှိ verification baseline

Native Rust test suite သည် unit နှင့် integration test baseline အားလုံး pass ဖြစ်ပါသည်။ P1-05 deterministic နှင့် replayable layer runner သည် parser/lexer/JSON/lockfile/security corpus၊ fixed-seed category ခြောက်မျိုး replay၊ durable fixture evidence၊ collection regression နှင့် async cancellation/scheduler cases များကို အောင်မြင်စွာ run လုပ်သည်။ M2-VERIFY-01 bounded replay job သည် သတ်မှတ်ထားသော round များအတွင်း category ခြောက်မျိုး semantic replay ကို ထပ်ခါ run လုပ်ပြီး fail-closed corpus-size limit များအောက်တွင် outcome digest တူညီကြောင်း အတည်ပြုသည်။ M2-VERIFY-02 matrix သည် zero-test filter match ကို အောင်မြင်မှုဟု မယူဆဘဲ target-native regression တစ်ခုချင်းစီကို run လုပ်ပြီး platform archive result ကို target log ထဲတွင် မှတ်တမ်းတင်သည်။ M2-REG-01 transport corpus သည် registry index နှင့် artifact fetch များတွင် အသုံးပြုသော client reader တစ်ခုတည်းမှတစ်ဆင့် chunked၊ truncated၊ delayed နှင့် oversized response fixture များကို run လုပ်သည်။ Release preflight သည် deployment validation မတိုင်မီ ownership၊ native/legacy parity၊ fixed-seed replay၊ bounded replay နှင့် focused async contract gate များကို run လုပ်သည်။ [`examples/default_parameters.zp`](../examples/default_parameters.zp) ကိုလည်း run စမ်းပြီး အောင်မြင်ပါသည်။ Type-narrowing၊ package၊ standard-library၊ benchmark နှင့် release guides များကို English/Burmese နှစ်ဘာသာဖြင့် synchronize ပြုလုပ်ထားပါသည်။ Native CLI version output သည် `v1.0.0` release line နှင့် ကိုက်ညီပါသည်။ `cargo fmt --check` နှင့် `git diff --check` လည်း pass ဖြစ်ပါသည်။ Stable Rust Clippy ကို GitHub Actions release workflow တွင် enforce လုပ်ထားပြီး local sandbox တွင် Clippy component မရှိသည့်အတွက် local result အဖြစ် မကြေညာထားပါ။

## P1 ပြီးစီးမှုနှင့် နောက်ထပ် roadmap

| ဦးစားပေး | အလုပ် | လက်ရှိအခြေအနေ | ပြီးစီးရန် လက်ခံစံနှုန်း |
|---:|---|---|---|
| 1 | Direct AST call evaluation | လက်ရှိ runtime call set အတွက် ပြီးစီး | Native AST သည် functions၊ methods၊ closures၊ indexing၊ pure built-ins၊ filesystem၊ environment၊ path၊ time helpers၊ native `new(...)` နှင့် default expression များကို တိုက်ရိုက် evaluate လုပ်သည်။ Callable frame များသည် defining module base ကို အမွေဆက်ခံသဖြင့် nested relative import ကို မှန်ကန်စွာ resolve လုပ်နိုင်သည်။ Unsupported named built-in call များကို deterministic အဖြစ် reject လုပ်ပြီး hidden reparse မရှိကြောင်း edge-case regression suite က စစ်ဆေးသည် |
| 2 | Named arguments | Built-in boundary အတိအကျဖြင့် ပြီးစီး | Named argument များကို user-defined function၊ method နှင့် closure များတွင် ဆက်လက်အသုံးပြုနိုင်သည်။ Built-in call များကို future contract က သီးခြားခွင့်ပြုမှသာ အသုံးပြုနိုင်ပြီး လက်ရှိတွင် reject လုပ်သည် |
| 3 | Control-flow type narrowing | ပြီးစီး | Single guards၊ complex boolean `and`/`or`၊ alias variables နှင့် else branch ပြီးနောက် မူလ option/result type ပြန်လည်ရရှိမှုကို support လုပ်ပြီးဖြစ်သည်။ Nested-flow analysis နှင့် guard diagnostics များကို ဆက်လက်တိုးချဲ့ရန်လိုသည် |
| 4 | OOP visibility နှင့် initialization rules | ပြီးစီး | Module-aware field coverage ပိုမိုတိုးချဲ့ခြင်းနှင့် constructor diagnostics refinement ကို ဆက်လက်လုပ်ဆောင်ရန်လိုသည် |
| 5 | Standard-library extraction/stabilization | အခြေခံအဆင့် ပြီးစီး | API contract hardening နှင့် future namespace exposure ကို ဆက်လက်လုပ်ဆောင်ရန်ရှိသော်လည်း deterministic public domain catalog နှင့် ဘာသာနှစ်မျိုး index များ ပြီးစီးပြီ |
| 6 | Package determinism နှင့် CLI tooling | အခြေခံအဆင့် ပြီးစီး | Canonical `zap.lock` generate လုပ်ခြင်း၊ sorted dependency entries၊ missing/stale lockfile rejection၊ stable diagnostics၊ explicit `--locked` install/build mode၊ project checks နှင့် version/help consistency |
| 7 | Cross-platform နှင့် release gates | P1 release အတွက် ပြီးစီး | Linux၊ Windows နှင့် macOS matrix build များတွင် CLI version/help/example smoke checks ပါဝင်ပြီး bilingual release changelog၊ ownership/parity/replay/async contract gate နှင့် release workflow packaging ပြီးစီးပါပြီ |

Gradual-typing baseline သည် support လုပ်ထားသော syntax boundary အတွင်း ပြီးစီးပါပြီ။ Primitive နှင့် bounded generic annotation များ၊ function argument/return၊ option/result payload၊ control-flow narrowing၊ structured diagnostic နှင့် TC-001–TC-012 conformance evidence များကို English/Burmese ဖြင့် မှတ်တမ်းတင်ထားပြီး advanced user-defined generic declaration နှင့် inference များကို အတိအလင်း နောက်ရွှေ့ထားပါသည်။ Clean-machine locked verification သည် registry access မလိုဘဲ copy လုပ်ထားသော project မှ `zap install --locked` နှင့် `zap build --locked` ကို run နိုင်ကြောင်း၊ tampered lockfile ကို reject လုပ်ကြောင်း သက်သေပြပါသည်။ Direct-AST migration သည် လက်ရှိ runtime call set အတွက် ပြီးစီးပြီး nested-call audit coverage၊ native object construction၊ AST-evaluated default နှင့် explicit unsupported-call diagnostic များ ပါဝင်သည်။ Parser ပိုင် execution သည် legacy expression reparse ကို hidden အဖြစ် မထားတော့ပါ။ Standard-library public surface တွင် deterministic domain metadata နှင့် ဘာသာနှစ်မျိုး index များ ပါဝင်ပါသည်။ CI တွင် platform-specific CLI smoke checks များ ပါဝင်ပါသည်။ Package tooling တွင် deterministic local dependency declarations နှင့် canonical lockfile validation ပါဝင်ပါသည်။ Remote registry resolution နှင့် publishing များမှာ နောက်ပိုင်း ecosystem အလုပ်များ ဖြစ်ပါသည်။ Named arguments၊ OOP visibility၊ protected inheritance၊ field initialization၊ module-aware access နှင့် constructor delegation rules များကို P1 တွင် ပြီးစီးထားပါသည်။ Control-flow narrowing တွင် single guards၊ `and`/`or` guard combinations၊ aliases နှင့် `else` branch ပြီးနောက် မူလ option/result type ပြန်လည်ရရှိမှုကို support လုပ်ပြီးဖြစ်ပါသည်။ P1 release documentation ကို English/Burmese နှစ်ဘာသာဖြင့် synchronize ပြုလုပ်ထားပါသည်။ Executor-backed async scheduling နှင့် cooperative task control များကို အကောင်အထည်ဖော်ပြီးဖြစ်သည်။ M2-VERIFY-02 platform-native hardening လည်း ပြီးစီးပြီးဖြစ်သဖြင့် benchmark provenance နှင့် registry transport edge case များကို ဆက်လက်လုပ်ဆောင်ပြီးမှ M3 tooling/documentation milestone များသို့ ဆက်သွားမည်။
